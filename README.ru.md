# Tracery Filter — плагин для OBS

Видеофильтр для OBS Studio, который в реальном времени находит области определённого цвета, рисует вокруг них рамки и соединяет их линиями. Вдохновлён плагином Tracery для Adobe After Effects.

## Возможности

- **Детект цвета** — находит области заданного цвета с настраиваемым порогом
- **Ограничивающие рамки** — рисует прямоугольники вокруг найденных областей с настраиваемым цветом и толщиной
- **Угловой стиль** — возможность рисовать только углы рамки вместо полных сторон
- **Подписи с координатами** — отображает X/Y координаты над каждой областью с настраиваемым шрифтом, цветом и обводкой
- **Линии соединения** — соединяет области плавными кривыми Безье; поддерживает пунктир, настройку толщины и кривизны
- **Маркеры центра** — опциональные точки в центре каждой области
- **Два режима детекта** — стандартный попиксельный и сеточный для стабильной работы с шумными источниками (вебкамеры)
- **Сглаживание** — временное сглаживание позиций рамок между кадрами
- **Настройки производительности** — шаг сканирования и пропуск кадров для баланса качества и нагрузки на CPU
- Работает с любым источником OBS: захват игры, захват экрана, вебкамера, устройства захвата видео и сцены

## Требования

- OBS Studio 30.0 или новее
- Windows (плагин использует Windows GDI для рендеринга текста)

## Установка

1. Скачай последний релиз со страницы [Releases](../../releases)
2. Скопируй `tracery-plugin-for-obs.dll` в:
   ```
   C:\Program Files\obs-studio\obs-plugins\64bit\
   ```
3. Скопируй содержимое папки `data` в:
   ```
   C:\Program Files\obs-studio\data\obs-plugins\tracery-plugin-for-obs\
   ```
4. Перезапусти OBS Studio

## Использование

1. Правый клик на любом источнике в OBS → **Фильтры**
2. Нажмите **+** → выберите **Tracery Filter**
3. Выберите **Key Color** — цвет который нужно искать
4. Настройте **Threshold** пока нужные области не будут выделены
5. Настройте остальные параметры по вкусу

## Настройки

### Detection (Детект)
| Параметр | Описание |
|---|---|
| Key Color | Цвет для поиска |
| Threshold | Насколько точно пиксель должен совпадать с цветом (0 = точное совпадение) |
| Smoothing | Сглаживание позиций блобов между кадрами |
| Min Distance | Минимальное расстояние между отдельными блобами |
| Min Blob Size | Минимальный размер блоба в пикселях; меньшие игнорируются |
| Detection Quality | Шаг сканирования — больше значение, быстрее но менее точно |
| Update Every N Frames | Как часто запускается детект; снижает нагрузку на CPU |

### Alternative Detection (Альтернативный детект)
Сеточный режим детекта — рекомендуется для вебкамер и шумных источников.

| Параметр | Описание |
|---|---|
| Alternative Detection | Включить сеточный детект |
| Grid Cell Size | Размер ячейки сетки в пикселях |
| Cell Threshold | Минимальное количество совпадающих пикселей для активации ячейки |

### Bounding Boxes (Рамки)
| Параметр | Описание |
|---|---|
| Show Boxes | Показывать/скрывать рамки |
| Box Color | Цвет рамки |
| Boxes Thickness | Толщина линий рамки |
| Corner Style | Рисовать только углы вместо полных сторон |
| Corner Length | Длина каждого угла |

### Labels (Подписи)
| Параметр | Описание |
|---|---|
| Show Labels | Показывать/скрывать подписи с координатами |
| Font | Шрифт и размер |
| Text Color | Цвет текста |
| Outline | Включить обводку текста |
| Outline Color | Цвет обводки |
| Outline Thickness | Толщина обводки в пикселях |

### Markers (Маркеры)
| Параметр | Описание |
|---|---|
| Show Center Markers | Показывать/скрывать маркеры центра |
| Marker Color | Цвет маркеров |

### Connection Lines (Линии)
| Параметр | Описание |
|---|---|
| Show Lines | Показывать/скрывать линии |
| Line Color | Цвет линий |
| Line Thickness | Толщина линий |
| Curvature | Кривизна линий Безье (0 = прямые) |
| Dashed Lines | Включить пунктирный стиль |
| Dash Length | Длина каждого штриха |
| Gap Length | Длина пробела между штрихами |

## Сборка из исходников

### Требования
- Visual Studio 2022
- CMake 3.30+

### Шаги

```cmd
git clone https://github.com/kiraping1337/obs-tracery-filter.git
cd obs-tracery-filter
cmake --preset windows-x64
cmake --build build_x64 --config RelWithDebInfo
cmake --install build_x64 --config RelWithDebInfo
```
